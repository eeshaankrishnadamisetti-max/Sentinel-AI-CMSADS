# Sentinel-AI Roadmap

### Phase 1 — Simulation (Current)
- Develop PoC with random sensor data
- Build baseline RandomForest model
- Demonstrate alert system locally

### Phase 2 — Hardware Testing
- Connect live RF and IR sensors
- Capture real signatures
- Train lightweight CNN

### Phase 3 — Deployment
- Multi-node testing (mesh)
- Cloud dashboard (MQTT)
- Real-time visualization
